# Public-evidence policy

Architecture, detection flow, test cases, and investigation logic are represented with Mermaid and Markdown so the portfolio remains useful without publishing raw coursework screenshots, packet captures, account details, or lab-provider content.

Any future dashboard image must use synthetic telemetry and fictional identifiers. The underlying query and interpretation must remain available as text so the result is reproducible and accessible.
# Image checklist

Add only new, sanitized images from the independent extension:

- Network topology using documentation-safe ranges
- Protocol distribution chart from synthetic data
- SIEM query and result
- Anomaly visualization with fictional identifiers
- Investigation timeline

Do not publish raw coursework screenshots, packet captures, account details, or lab-provider content.
